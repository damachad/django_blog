# Blog with Django
This project makes use of Django to create a simple Blog website, with users being able to:   
- sign up
- log in and out   
- create posts
- edit and delete their posts
- add comments to posts
- delete comments from their posts  
- update their profile info
- choose a profile picture
- see other users' profiles
